# Temporal and Vertical Patterns in Microbial ATP at Station ALOHA

This project examines how microbial ATP concentrations vary vertically and temporally at Station ALOHA using the Hawaii Ocean Time series (HOT) data collection program. CTD pressure is used as a vertical measurement for depth, assuming 1 decibar is approximately 1 meter in depth. This project also looks into other variables such as carbon and phaeopigments to see if there are other proxies for microbial biomass that could be used. 

### Data source

Data were accessed through HOT-webODV
